# win98-desktop

*[Versão em português](README.md)*

Turns Linux into Windows 98: windows, taskbar, Start menu, menus, icons, cursor, sounds, popups and
even Firefox, which becomes Netscape.

This first version is for **KDE Plasma 6**. The plan is to adapt it to other desktops later
(Hyprland, GNOME…), see [Plans](#plans).

Tested on **Fedora 44, KDE Plasma / KWin 6.7.5, Qt 6.11, Wayland**, with two monitors. Nothing is
tied to screen pixels: everything follows the size of the windows and monitors.

Made by **Leonardo Borges** with help from **Claude** (Anthropic), on top of the work of many people:
icons from Chicago95 and SE98, Netscape artwork from FOXSCAPEuC, measurements from 98.css and more.
The full list, with links and licenses, is in **[CREDITS.md](CREDITS.md)**.

## What the theme changes

**Windows**
- Navy gradient title bar with the 98 [_][□][X] buttons (Aurorae `Win98`, exact measurements
  generated by `gen_decoration.py`).
- Custom animations (`kwin/win98windows`): opening unrolls the window from its title bar; closing
  rolls it back up; minimizing shrinks it into its taskbar button.
- Menus, submenus and popups slide out from where they were opened, like in 98, and close
  instantly (`kwin/win98menuslide`).

**Taskbar and Start menu**
- Gray beveled panel, 40px, stuck to the screen edge; buttons look pressed when the window is
  active; the 98 black arrow when an app has more than one window.
- A real "Start" button that presses in when clicked (a modified copy of Kickoff 6.7.5 in
  `plasmoides/`), with no hover tooltip.
- Clock with date; tray with all icons visible; media controls with the CD Player button.

**Plasma popups** (notifications, tray, calendar…)
- 98 "little window": gray beveled body, blue header with white text, close button like the windows'.
- Beveled buttons that press in, yellow tooltip with black border, 98 scrollbar, on/off switches
  drawn as checkboxes.

**Qt/KDE apps** (Kvantum `Win98` + QML layer `qml/org/kde/win98`)
- 3D beveled buttons, fields, menus, tabs and scrollbars; 98 checkboxes and radio buttons.
- Lists with a line between items, navy selected item and a "pressed" look on hover.
- On/off switches become checkboxes.

**Icons, cursor, font and sounds**
- Chicago95 + SE98 icons, with gaps filled and modern apps getting 98 artwork (Wine, KDE
  utilities, Discord, Chrome in pixel art); brand apps like OBS keep their logo.
- White Chicago95 cursor at 32px; Liberation Sans 10; new sounds in the 98 style.
- Teal wallpaper (#008080), the 98 default.

**Firefox = Netscape Communicator** (`extras/firefox`)
- System title bar, 98 tabs, Netscape buttons (green arrows, traffic light, little house),
  "Address:" label, the Netscape "N" spinning while loading, 98 menus, 98 form suggestion list.
- Websites stay in dark mode (`layout.css.prefers-color-scheme.content-override = 0` in `user.js`;
  delete that line if you prefer light websites).

## Install

You need KDE Plasma 6 plus: `kvantum` (Fedora's package already ships the Qt 6 plugin), `python3`
with `Pillow` and `PySide6`, `kiconfinder6`, `curl`. On Fedora:

```sh
sudo dnf install kvantum python3-pillow python3-pyside6 kf6-kiconthemes
git clone https://github.com/XxPregoxX/win98-desktop.git
cd win98-desktop
./instalar.sh
```

`instalar.sh`:
1. checks that everything it needs is installed;
2. downloads Chicago95 and SE98 from their original repositories (`ferramentas/baixar_terceiros.sh`,
   about 40MB) and applies the icon fixes (`ferramentas/refazer_icones.sh`);
3. links the files in this folder into the places KDE looks at (symlinks, listed in `.links`);
4. applies the settings (colors, style, icons, cursor, font, decoration, effects, panel, wallpaper,
   Start button) and restarts plasmashell;
5. installs the Firefox theme into the default profiles (`chrome` link + preferences added to `user.js`).

Before changing anything, it saves whatever was in place of the links and the Plasma settings to
`backups/antes-da-instalacao-<date>/`. Cursor and font may need a log out and back in. Don't delete
the folder after installing: the system uses the files in it.

`./instalar.sh --so-links` only recreates the links, without touching settings.

## Uninstall

```sh
./desinstalar.sh --simular   # shows what it would do
./desinstalar.sh
```

Goes back to Breeze (colors, style, icons, cursor, decoration, effects), puts the original Kickoff
back in place of the Start button, and removes the links and the Firefox theme. Wallpaper and panel
height stay as they are. You can also go back through System Settings (pick Breeze in Colors, Plasma
Style, Window Decorations, Application Style, Icons and Cursors).

## How it works

The files live **in this folder**. The places KDE looks at (`~/.local/share/...`, `~/.config/...`)
are symlinks to here: edit here and it applies to the system. Almost all artwork (Plasma SVGs,
Kvantum, Aurorae, generated icons) comes from scripts in `ferramentas/`: **edit the script, not
the SVG**.

| Folder | Contents | Becomes |
|---|---|---|
| `temas/color-schemes/` | `Win98` color scheme | System colors |
| `temas/aurorae/Win98/` | Title bar and buttons | Window decoration |
| `temas/kvantum/Win98/` | 3D widget bevels | Qt app style |
| `temas/plasma/Win98/` | Panel, taskbar, popups, buttons, tooltip, scrollbar, switches | Plasma style |
| `temas/icones/botao-iniciar/` | Start button images (normal and pressed) | Start button |
| `temas/icones/chicago95-ajustes/` | Final icons and list of Chicago95 fixes | Icons |
| `temas/sons/Win98/` | Synthesized sounds (login, error, ding…) | Sounds |
| `kwin/win98menuslide/` | Effect: menus slide like in 98 | Menu animation |
| `kwin/win98windows/` | Effect: open/close/minimize windows | Window animation |
| `plasmoides/org.kde.plasma.win98kickoff/` | Modified copy of Kickoff 6.7.5 | Start menu |
| `qml/org/kde/win98/` | QML style layer on top of KDE's style | Lists and switches in QML apps |
| `extras/firefox/` | `user.js` and `chrome/` (userChrome + Netscape artwork) | Firefox |
| `extras/env/` | QML layer variables (loaded at login) | — |
| `extras/kvantum/`, `extras/win98-startup.desktop` | Kvantum config, login sound | — |
| `terceiros/` | Third-party packages downloaded at install time (only the 2 Win95 +PLUS+ icons ship with the repo) | Icons, cursor |
| `ferramentas/` | Generators, icon fixes, package download and tests | — |
| `docs/prints/` | README screenshots | — |
| `LICENSES/` | License texts | — |

## Known limitations

- Minimizing is not the 98 "title bar zoom" (only the title bar flying): a KWin JS effect can't
  show just the title bar away from the window's place, so the whole window flies.
- Plasma scrollbar without arrows and with the track only on hover (hardcoded in Plasma).
- Taskbar thumbnail tooltips keep KDE's layout (would need a compiled copy of the task manager).
- Chrome notifications show the modern logo: Chrome sends its built-in logo as a file.
- Qt Widgets lists (Dolphin etc.) have no line between items (Kvantum doesn't draw it).

## Good to know

- **Start button (Kickoff copy)**: if a Plasma update breaks the Start menu, run
  `./desinstalar.sh` or revert only the menu: with plasmashell stopped (`kquitapp6 plasmashell`),
  replace `plugin=org.kde.plasma.win98kickoff` with `org.kde.plasma.kickoff` in
  `~/.config/plasma-org.kde.plasma.desktop-appletsrc` and run `kstart plasmashell`.
- **QML style layer** (`qml/org/kde/win98`): enabled by the variables in `extras/env/win98-qml.sh`,
  which Plasma loads at login. If a QML app stops opening after a KDE update, delete
  `~/.config/plasma-workspace/env/win98-qml.sh` and log out and back in.
- **Firefox**: the installer replaces an existing `chrome` folder in the profile with the theme
  (yours goes to the backup). Restart Firefox to see it.

## Plans

- **Dark mode**: a "dark 98", same bevels with dark colors, and an easy way to switch.
- **Other desktops**: Hyprland first, maybe GNOME. Almost everything here is KDE-specific (Plasma,
  KWin, Kvantum, Aurorae), but the icons (freedesktop theme), cursor, sounds, the whole Firefox

  outside KDE with `QT_STYLE_OVERRIDE=kvantum`) can be reused.
